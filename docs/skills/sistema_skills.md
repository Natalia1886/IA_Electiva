# Skills de Dominio e Integración

Documentación de los componentes de habilidad (Skills) registrados en `SKILL_REGISTRY`.

## Skills de Dominio
- **`db_repository`**: Abstracción de acceso y persistencia a la base de datos (SQLite / ORM local).
- **`stock_monitor`**: Análisis en tiempo real de niveles de stock y generación de alertas por desabastecimiento.
- **`demand_forecaster`**: Modelo predictivo para estimar demanda futura basada en historial y fechas festivas.
- **`product_segmentation`**: Clasificación y segmentación de catálogo de productos.
- **`nl_explainer`**: Generador de explicaciones en lenguaje natural para decisiones del sistema de recomendación.
