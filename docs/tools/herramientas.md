# Integraciones y Herramientas Utilitarias (`tools/`)

Documentación de los módulos utilitarios para integraciones de infraestructura e interfaces externas.

## Herramientas Disponibles
- **`tools/github_client.py`**: Integración con la API de GitHub para la gestión de repositorios y operaciones Git.
- **`tools/slack_client.py`**: Integración con la API de Slack para el envío de notificaciones y comunicación de eventos.
