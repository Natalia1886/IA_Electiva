# Endpoints y Rutas de la API REST

Documentación de los módulos HTTP construidos sobre FastAPI en `interfaces/api/`.

## Endpoints Disponibles
- **`/api/auth`**: Autenticación y control de usuarios.
- **`/api/products`**: Gestión del catálogo de productos y precios.
- **`/api/sales`**: Registro de ventas, transacciones e historial.
- **`/api/inventory`**: Consulta de stock, ajustes y alertas.
- **`/api/festivities`**: Calendario de festividades religiosas asociadas al consumo.
- **`/api/recommendations`**: Sugerencias de compras generadas por el motor inteligente.
- **`/api/dashboard`**: Métricas clave y resumen ejecutivo.
